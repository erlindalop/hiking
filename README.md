# Hiking 
This is to register tourist and tourist places so that the tourists can chose a good place to go 

## Set up the proyect
Create venv
```
uv venv
```


Activate venv
```
source .venv/bin/activate
``` 
## Run the project
```
uv run fastapi dev src/main.py
```

## Set up with docker
this projet is runing with docker.So to run the projet use docker commands 
to avoid docker commands use make commands 

```
 make up 
```
